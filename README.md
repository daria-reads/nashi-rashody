# Наши расходы

Общий учёт расходов на двоих. Вход через Google, данные хранятся в Firebase (Firestore), сайт размещается на GitHub Pages бесплатно.

Доступ к тратам есть только у двух Google-аккаунтов, которые вы впишете в правила базы. Любой другой человек, даже если откроет ссылку и войдёт, ничего не увидит.

## Что в папке

- `index.html` — само приложение
- `firebase-config.js` — сюда вставляются настройки вашего проекта Firebase
- `firestore.rules` — правила доступа: кто может читать и записывать траты

## Шаг 1. Создать проект Firebase

1. Откройте https://console.firebase.google.com и войдите своим Google-аккаунтом.
2. **Create a project** → придумайте название, например `nashi-rashody`. Google Analytics можно выключить.
3. В проекте нажмите значок **</>** (Web), назовите приложение, «Firebase Hosting» не отмечайте → **Register app**.
4. Появится блок `const firebaseConfig = { ... }`. Скопируйте значения в файл `firebase-config.js`, заменив строки «ВСТАВЬТЕ_СЮДА».

## Шаг 2. Включить вход через Google

1. Слева **Build → Authentication → Get started**.
2. Вкладка **Sign-in method** → **Google** → включить → укажите свою почту поддержки → **Save**.

## Шаг 3. Создать базу и защитить её

1. Слева **Build → Firestore Database → Create database**. Расположение — любое европейское (например, `europe-west`), режим — **production**.
2. Вкладка **Rules**: удалите всё, что там есть, и вставьте содержимое файла `firestore.rules`.
3. В правилах замените `daria@gmail.com` и `muzh@gmail.com` на ваши настоящие Google-адреса → **Publish**.

## Шаг 4. Выложить на GitHub Pages

1. На https://github.com создайте новый репозиторий (**New**), например `nashi-rashody`. Подойдёт и публичный — в файлах нет ничего секретного.
2. **Add file → Upload files** → перетащите `index.html`, `firebase-config.js` (уже с вашими настройками) и `firestore.rules` → **Commit changes**.
3. **Settings → Pages** → в «Branch» выберите `main` и папку `/ (root)` → **Save**.
4. Через минуту-две сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/nashi-rashody/`.

## Шаг 5. Разрешить вход с этого адреса

1. В Firebase: **Authentication → Settings → Authorized domains → Add domain**.
2. Впишите `ВАШ-ЛОГИН.github.io` (без `https://` и без названия репозитория) → **Add**.

Готово. Откройте сайт, войдите через Google, а ссылку отправьте мужу — он войдёт своим аккаунтом из списка.

## Если что-то не работает

- **«Аккаунт … не входит в список»** — проверьте, что адрес в `firestore.rules` написан точно так же, и правила опубликованы.
- **Окно входа не открывается или выдаёт `auth/unauthorized-domain`** — не добавлен домен на шаге 5.
- **Пустая страница** — скорее всего, в `firebase-config.js` остались «ВСТАВЬТЕ_СЮДА» или пропущена кавычка.
- Сайт можно добавить на главный экран телефона: в браузере «Поделиться» → «На экран Домой».

Бесплатного тарифа Firebase (Spark) для двоих хватит с большим запасом.
